# Launch Deck

Start and watch several projects from one window — your frontend, backend, or any command you would normally run in a terminal.

<h1>
  <a href="https://github.com/patilniranjanr2020/lunch-deck/releases/download/v0.1.0/LaunchDeck_0.1.0_x64-setup.exe">⬇ Download for Windows</a>
</h1>

Open the installer, follow the steps, then launch **Launch Deck** from the Start menu.

---

## How to use it

### 1. Add a box for each project

Click **+ Add Runner Box**. Make one box for each thing you want to run (for example: website, server, or script).

<img src="docs/screenshots/1.png" alt="Add a runner box" width="100%" />

### 2. Type the command

Enter the same command you would type in a terminal, such as `npm run dev` or `python app.py`.

<img src="docs/screenshots/2.png" alt="Enter the command" width="100%" />

### 3. Choose the folder and press Start

Pick the project folder, then press **START**.

<img src="docs/screenshots/3.png" alt="Choose the folder and start" width="100%" />

### 4. Watch it run

You’ll see whether it is running, any website links it prints (click to open in your browser), and the live log output. You can stop it, copy the log, or clear it when you are done.

<img src="docs/screenshots/4.png" alt="Running project with links and logs" width="100%" />

---

Your boxes, commands, and folders are saved on your computer, so they come back the next time you open the app.
